개선 포인트 — 검색과 상태

  1. 팔레트는 실제 데이터를 검색. 현재 명령 팔레트는 존재하지 않는 고정 ID(distributed-lock, kafka-rebalance, ?company=stripe)를 가리키는 15개 하드코딩 항목. 질문·이력서 항목·이동 명령을 서버 검색 + 최근 항목으로.
  2. 상태 4종을 공통 컴포넌트로. 현재 404 라우트와 errorElement/ErrorBoundary가 없어 런타임 오류 시 React Router 기본 개발자 화면(“Hey developer 👋”)이 사용자에게 노출됨. 백엔드 원문 오류 메시지 대신 사용자 문장 + 복구 행동.
