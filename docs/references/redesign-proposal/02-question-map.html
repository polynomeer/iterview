개선 포인트 — 질문 (기존: /practice, /questions/:id, /questions/:id/tree 3개 페이지 통합)

  1. 위치는 항상 한 줄로. 트리 + 경로(breadcrumb) + 깊이 배지. 기존의 “질문 경로 맥락 / 깊이 2 / 분기 1개 중 1개” 카드, 세로로 꺾인 “카테고리·난이도·회사 수” 컬럼 제거.
  2. 질문 상세와 트리를 한 화면에. 트리에서 노드를 고르면 가운데가 바뀌고, “맵으로 돌아가기/이전/다음” 왕복이 필요 없음.
  3. DFS는 용어가 아니라 동작으로. “DFS 집중/전체 경로” 토글 대신 “다음 꼬리질문”을 확률순으로 제시.
  4. 인스펙터는 사실만. 기존 우측 레일의 ‘마스터리 점수/0/0’ 무라벨 타일과 버튼 4개(답변 시작·빠른 복습·리뷰에 추가·노트로 이동)를 점수 이력 + 이력서 연결 + 자료 + 메모로 정리. 스킬 페이지의 ‘맵’ 보기는 여기 트리/맵 토글로 흡수.
