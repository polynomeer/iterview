개선 포인트 — 설정 (기존 /profile, /settings, /target-companies 3개 통합)

  1. 계정 관련은 한 곳. 프로필 페이지 → 설정 링크 → 목표 회사 별도 페이지로 흩어진 구조를 설정 하위 섹션으로. 프로필은 사이드바에 없고 헤더 아바타로만 진입했음.
  2. 목표 회사는 실데이터. 기존 목표 회사 페이지는 하드코딩 배열(TARGET_COMPANIES) 기반. /api/me/target-companies로 교체.
  3. 테마 4종 → 시스템/라이트/다크. 현재 기본 ‘light’ 테마에서 어두운 카드가 밝은 배경 위에 렌더링돼 페이지 제목·사이드바 ‘관리’ 메뉴·로그인 라벨이 사실상 보이지 않음. ‘workspace’, ‘dracula’는 제거하고 prefers-color-scheme 지원.
