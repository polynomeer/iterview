  1. 버전은 전역 컨텍스트. 활성 버전을 상단 한 곳(+사이드바 하단 전환기)에서 바꾸고, 하위 화면은 모두 이 버전 기준. 기존에는 버전 선택·활성화 UI가 페이지마다 반복.
  2. 탭으로 통합. 항목과 근거(편집기) / 면접 압박 지도(히트맵) / 공고 맞춤(테일러) / 버전 기록. URL은 /resume/:versionId/{claims|heatmap|tailor|versions}.
  3. “기준 문서(source of truth)”를 작업 단위로. 추상 용어 대신 “항목 하나 = 상황·역할·측정 방법·결과”를 채우는 폼. 비어 있는 필드를 면접 위험과 직접 연결.
